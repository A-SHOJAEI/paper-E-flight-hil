# Flight-Class Processor-in-the-Loop Validation of a Reliability-Asymmetric GNC Stack

Flight-class validation of the AMPLE-GNC stack on three measured fronts. The controller and runtime shield are taken to processor-in-the-loop on real flight-class edge compute (Raspberry Pi 5, ARM A76 class), the verified shield is run live in the closed loop, and a high-fidelity fault campaign drives the deployed stack through the actuator and sensor non-idealities a clean simulator omits. A physical air-bearing campaign is future work, specified by the fault-to-wheel mapping.

## Reproduce

Run from the **repository root** (this folder). The package layout is preserved
so `python -m package.module` resolves directly:

```bash
pip install -r requirements.txt
python -m paper.hil.tables  # pure: flight-class + closed-loop + high-fidelity tables
python -m sil.integration.hifi_campaign  # high-fidelity fault campaign (needs Basilisk)
python -m sandbox.airbearing.hardware_loop --backend sim  # future air-bearing loop (sim)
```

## Status

HONEST STATUS: all three fronts are measured. The flight-class compute timing (`evidence/sandbox/pi_a53_gate.json`), the live runtime shield (`evidence/program/closed_loop_integration.json`), and the high-fidelity fault campaign (`evidence/program/hifi_fault_campaign.json`) are surfaced by `paper.hil.tables`. On the faults the estimator is designed for, the deployed recovery is statistically unchanged from ideal under the non-ideality model, and the verified shield escalates every fault beyond that scope. The PHYSICAL air-bearing campaign is FUTURE WORK; `hardware_loop.py --backend sim` documents the loop and the fault-to-wheel mapping that specifies it. The table generator is pure NumPy and runs from a clean checkout; the high-fidelity campaign requires Basilisk.

### Trained checkpoints (not shipped)

Learned weights (`checkpoints/*.pt`, `checkpoints/commander_*.gguf`) are large binaries and are **not** included. Each is regenerated by its training entry point in this repo (the RMA students via the `controller.rma.*` training mains; the commander via the `commander.nl_pddl.*` training mains). The committed `evidence/*.json` files let the manuscript tables/figures reproduce **without** the weights.

### Basilisk

Fresh high-fidelity runs use the Basilisk 6-DOF simulator. Install with `pip install bsk`. Basilisk-gated code paths skip gracefully when it is absent, and the pure-NumPy reproduce commands above do not need it.
